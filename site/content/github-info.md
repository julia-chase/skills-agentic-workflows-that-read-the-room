### From Awesome Copilot

The `awesome-copilot.github.com/workflows/` page has been retired; the project reorganized its
catalog into `/agents/`, `/skills/`, `/instructions/`, and `/extensions/` sections. The **Agents**
catalog is the closest match to the old workflows list, with 200+ community-built custom agents
for specific stacks and tasks (for example, a ".NET Self Learning Architect" agent for complex
.NET delivery). *(Source: Awesome Copilot)*
