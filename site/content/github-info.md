## Quick tips for new developers

- Use pull request templates and draft PRs to get early feedback before code is ready for review.
- Enable branch protection rules on `main` to require reviews and passing checks before merging.
- Try GitHub Copilot's inline chat in your IDE to explain unfamiliar code before making changes.
